# 🧠 Deep Learning Projects
### Medical Image Analysis | Computer Vision | Convolutional Neural Networks

Welcome to my collection of deep learning projects focused on applying artificial intelligence to medical image analysis.

These projects were developed during my academic studies in Electrical Engineering and Biomedical Engineering, with a particular focus on exploring how deep neural networks can be used to analyze medical imaging data.

The repository includes work on **brain tumor classification using MRI** and **cerebral hemorrhage detection using CT scans**, involving the implementation and comparison of different convolutional neural network (CNN) architectures.

## 🔬 Project 1: Brain Tumor Classification Using MRI

**Bachelor's Thesis | Electrical Engineering – Control Engineering**

### Overview

This project investigates the application of deep learning to brain tumor classification using MRI images.

The goal was to explore how convolutional neural networks and transfer learning could be applied to medical image classification, and to compare the performance of different architectures.

### Dataset

**Br35H Brain MRI Dataset**

- Approximately 3,000 MRI images
- Brain tumor classification task
- Medical image preprocessing and classification

### Models

The project involved working with:

- **ResNet50** — A deep residual neural network architecture
- **VGG16** — A convolutional neural network architecture
- **Transfer Learning** — Adapting pretrained models to the MRI classification task

### Methodology

The project involved:

1. Preparing and preprocessing MRI images.
2. Implementing CNN-based classification models.
3. Applying transfer learning using pretrained architectures.
4. Training and evaluating the models.
5. Comparing the performance of different architectures.
6. Developing a graphical user interface (GUI) for the application.

### Skills Demonstrated

`Python` · `Deep Learning` · `CNNs` · `Transfer Learning` · `Medical Image Processing` · `Model Evaluation` · `GUI Development`

## 🩺 Project 2: Cerebral Hemorrhage Detection Using CT Images

**Academic Research Project | Advanced Process Automation & Control Research Group**

### Overview

This project focused on applying deep learning techniques to the detection of cerebral hemorrhage in CT scan images.

The aim was to investigate and compare multiple CNN architectures for analyzing brain CT images and identifying hemorrhage-related patterns.

### Models

Several convolutional neural network architectures were explored:

| Architecture | Model Family |
|---|---|
| ResNet34 | Residual Neural Network |
| ResNet50 | Residual Neural Network |
| ResNet101 | Residual Neural Network |
| VGG16 | VGG Network |
| VGG19 | VGG Network |

### Methodology

The project involved:

1. Working with a medical CT image dataset.
2. Preparing images for deep learning models.
3. Implementing multiple CNN architectures.
4. Training and evaluating classification models.
5. Comparing the behavior and performance of different architectures.

### Skills Demonstrated

`Python` · `Computer Vision` · `Medical Imaging` · `CNN Architectures` · `Deep Learning` · `Model Comparison`
